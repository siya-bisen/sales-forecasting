## ❓ FAQ

**Q: Do I have to add optional columns?**
A: No! Your CSV works with just date and sales. Optional columns enhance the analysis.

**Q: Which columns should I add first?**
A: Start with ProductCategory and Region for immediate business insights.

**Q: Will my old CSVs still work?**
A: Yes, 100% backward compatible. Existing files work as before.

**Q: How much better are the forecasts?**
A: With context, AI understands business dimensions and provides more personalized insights.

**Q: Can I add all optional columns?**
A: Yes! More context = deeper analysis. Add as many as you have data for.
